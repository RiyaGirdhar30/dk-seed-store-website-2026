# 🌱 DK Seed Store Website

A full-stack e-commerce web application developed for purchasing agricultural seeds online. The platform provides a responsive and user-friendly shopping experience where users can browse products, search and filter seeds, view detailed product information, manage their shopping cart, and place orders. The application is built using React.js for the frontend and Node.js, Express.js, and MongoDB Atlas for the backend.

> **Note:** This repository contains both the **Frontend** and **Backend** of the application.

## ✨ Features

- 🌱 Browse agricultural seed products
- 🔍 Real-time product search
- 📂 Category-wise product filtering
- 📄 Product details page
- 🛒 Add products to shopping cart
- ❌ Remove products from cart
- 💰 Automatic total price calculation
- 🔄 Dynamic product data using REST APIs
- 🛠️ Admin dashboard for product management
- ➕ Add new products
- ✏️ Update existing products
- 🗑️ Delete products
- 💳 Cash on Delivery (COD) support
- 📱 Fully responsive design

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/RiyaGirdhar30/dk-seed-store-website.git
```

---

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

---

### Install Backend

```bash
cd backend
npm install
npm start
```
